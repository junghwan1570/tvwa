# 명왕사신TV (TVwa Tesla Web TV)

TVwa 앱을 웹으로 옮긴 테슬라 차량 브라우저용 실시간 TV "명왕사신TV"입니다. `index.html` 파일 하나로 동작합니다.

- 주소: https://junghwan1570.github.io/tvwa/
- 채널 출처: 기존 TVwa 채널 목록 + iptv-org 공개 재생목록 (https://github.com/iptv-org/iptv)
- DRM·유료 구독·인증·지역 제한은 우회하지 않습니다. 방송사나 권리자가 공개한 스트림만 연결합니다.

## 실행 방법

1. 이 저장소의 `index.html`을 GitHub Pages(Settings → Pages → main / root)로 배포합니다. 다른 HTTPS 정적 호스팅(NAS 등)도 됩니다.
2. 테슬라 브라우저에서 위 주소를 엽니다.
3. 수정할 때는 `index.html`만 다시 올리면 됩니다. 빌드 과정은 없습니다.

`file://`로 직접 열면 YouTube가 재생을 막기 때문에 반드시 HTTPS로 열어야 합니다.

## 이번 변경 사항 (안드로이드 TV · 치지직 · 지역 묶기)

- **안드로이드 TV(쉴드TV) 지원**: 같은 앱이 TV에서는 리모컨 화면으로 뜹니다(휴대폰은 그대로). TV 홈 화면 배너, 리모컨 조작(OK·◀ 채널 목록, ▲▼·CH± 채널 이동, ▶ 방송 정보, 숫자 채널 번호, 메뉴 설정, 뒤로 두 번 종료). TV에서는 홈 버튼을 눌러도 작은 창(PIP)으로 바뀌지 않습니다.
- **MBC·SBS 지역 묶기**: 목록에는 MBC·SBS 하나씩만 나오고, "지역 ▾"(TV는 "지역 ▸")를 누르면 지역 방송을 고릅니다. 앱은 각 지역 방송의 원본 해상도를 확인해 높은 화질 순(1080p부터)으로 보여 줍니다. ▲▼ 채널 이동 때 지역 방송은 건너뜁니다. "지역방송" 탭과 검색에서는 모두 보입니다.
- **QQ 채널 출처 추가**: 코리아TV QQ 앱이 쓰는 출처(kenpark76 GitHub 재생목록·koreatv.json)를 같은 이름 채널의 추가 출처로 붙입니다(tvN 등). TV 화면에는 기존 명왕사신TV 채널만 나옵니다.
- **KBS 화질**: KBS API가 화질을 여러 개 주면 비트레이트가 가장 높은 주소를, KBS 케이블 채널은 HD 주소(`_hd.m3u8`)를 먼저 시도합니다.
- **SOOP → 치지직**: SOOP 인기 방송을 빼고 치지직 인기 생방송(앱 전용)을 넣었습니다. 앱이 치지직 API를 직접 받아 재생하고, 가장 높은 화질을 고릅니다. 19세 방송은 로그인이 필요해 재생되지 않습니다.
- **유튜브(앱)**: 앱에서는 "▶ 유튜브"를 누르면 공식 유튜브 앱(TV는 유튜브 TV 앱)이 열립니다. 웹(테슬라)은 지금처럼 인기 영상 목록입니다.

## 이번 변경 사항 (iptv-org 통합)

- **IPTV 탭 추가**: 한국 목록(`countries/kr.m3u`)을 기본으로 불러옵니다. "전체 국가"를 누르면 전체 목록(`index.m3u`)도 불러옵니다.
- **M3U 파서**: `#EXTINF`에서 채널명, `tvg-id`(국가 코드), `tvg-logo`, `group-title`(카테고리), 해상도, `[Not 24/7]` 같은 표시를 읽습니다. 따옴표 안의 쉼표도 처리합니다.
- **기존 목록과 중복 정리**: 재생 주소가 같거나 같은 채널명(예: `HLQS-DTV` = OBS)이면 기존 채널 하나만 보여줍니다. KTV 국민방송과 제주MBC는 재생이 확인된 iptv-org 스트림으로 기존 목록에 넣었습니다.
- **한국어 검색**: 지역 방송 호출부호 등에 한국어 이름을 붙였습니다(예: `HLCN-DTV` → 광주MBC). 카테고리도 한국어로 표시합니다.
- **필터**: 국가(전체 목록에서만), 카테고리, 재생 상태(재생 확인만 / 제외 숨기기 / 미검증 / 실패·제외).
- **새로고침과 보관**: 목록을 브라우저에 저장해 둡니다. 새로 받는 데 실패하면 이전 목록을 그대로 쓰고, 오류 원인과 "다시 시도" 버튼을 보여줍니다.
- **같은 화면 재생**: 채널을 바꾸면 플레이어 소스만 바뀝니다. 방송사 홈페이지를 iframe으로 띄우거나 새 탭으로 여는 채널은 없습니다.
- **재생 엔진**: HLS는 hls.js를 먼저 쓰고, 안 되면 브라우저 기본 HLS를 씁니다. MP4/WebM은 HTML5 video로 재생합니다. DASH(.mpd)는 검증된 방식이 없어 연결하지 않습니다.
- **오류 구분**: HTTP 혼합 콘텐츠, CORS 차단, 서버 응답 없음, HTTP 4xx/5xx, 잘못된 스트림 주소, 코덱 미지원, 영상 조각 로드 실패, 응답 시간 초과(15초), 전용 헤더 필요, 비공식 재전송, DASH를 구분해 보여줍니다. 무한 로딩 없이 "다시 시도"와 "목록으로" 버튼이 나옵니다.
- **재생 확인 표시**: 실제로 영상 프레임이 나온 채널만 "✓ 재생 확인 날짜"로 표시합니다. 처음 표시되는 결과는 배포 전 실측값이고, 사용 중 재생에 성공하거나 실패하면 그 기기의 결과로 바뀝니다. 확인 전인 채널은 "미검증"으로 표시합니다.
- **목록 재생 점검**: IPTV 탭의 "이 목록 재생 점검" 버튼을 누르면 현재 필터의 채널을 음소거 상태로 3개씩 실제 재생해 보고 결과를 기록합니다. 테슬라에서 직접 검증할 때 씁니다.
- **새 탭 항목 삭제**: 방송사 공식 페이지로 새 탭을 열던 채널(KBS·MBC·SBS·OBS·종편·케이블·일부 지역방송·국회방송·아리랑), SOOP 탭, 무료 플랫폼 탭, 음악 탭을 지웠습니다. 탭은 즐겨찾기·공중파·뉴스·삼성TV·IPTV입니다. 공중파 탭은 KBS → MBC(지역 MBC) → SBS(지역 민방) → EBS 순서입니다. 서울 MBC·SBS는 로그인하지 않으면 미리보기만 제공해서 넣지 않았습니다.
- **KBS 추가**: KBS가 자기 온에어용으로 공개한 라이브 API(`pwwwapi.kbs.co.kr`)는 로그인 없이 무료 SD 주소를 돌려주고 다른 사이트의 요청(CORS)도 허용합니다. 채널을 누를 때마다 이 API에서 주소를 새로 받아 재생하며, 시간 제한이 있는 재생 주소는 저장하지 않습니다. KBS Drama와 Joy는 영상 암호 키 요청이 403으로 막혀 있어 넣지 않았습니다(인증 우회 안 함).
- **삼성 TV 플러스 (사용자 요청)**: 삼성 공식 채널 목록(`vdapi.samsung.com`)의 한국 채널 167개를 `jmp2.uk` 리다이렉트로 풀어 삼성 FAST 영상 서버 주소를 얻고, 그 주소를 앱에 넣었습니다. 재생할 때는 중계 서버를 거치지 않고 영상 서버에서 바로 받습니다. PC 크롬 기준으로 125개는 영상이 나오고, 41개(MBC·SBS·JTBC 예능 등)는 HEVC 형식이라 소리만 나와서 "HEVC 채널" 묶음에 따로 두었습니다. 테슬라처럼 HEVC를 지원하는 기기에서는 화면이 나올 수 있습니다. 1개(우리의식탁)는 재생되지 않아 뺐습니다. 삼성이 영상 서버 주소를 바꾸면 해당 채널은 재생 실패로 표시됩니다.
- **무료 영화 채널**: OTTera 무료 광고형 채널인 한국영화 1·2·3(720p)을 삼성TV 탭 맨 위에 넣었습니다.
- **주소 비교 버그 수정**: 같은 경로에 쿼리만 다른 스트림(삼성 채널 69개)이 재생 확인 기록을 서로 덮어쓰던 문제를 고쳤습니다. 이제 시간 제한 토큰류 파라미터만 빼고 쿼리까지 비교합니다.
- **기타**: 음소거 버튼 추가, 즐겨찾기·최근 시청에 IPTV 채널 포함(새로고침 후에도 유지), hls.js CDN 로딩 실패 시 경고 띠 표시, 빠르게 채널을 바꿀 때 이전 스트림 정리가 새 스트림을 끊던 버그 수정.

## 정책상 제외하는 주소

| 사유 | 판단 기준 | 이유 |
|---|---|---|
| HTTP 주소 | `http://` 스트림 | HTTPS 페이지에서 브라우저가 차단합니다. 사용 권한이 있는 HTTPS 프록시(NAS 등)를 두면 재생할 수 있습니다. |
| 전용 헤더 필요 | `#EXTVLCOPT` 등으로 Referer·User-Agent 요구 | 헤더 위조는 우회라 하지 않습니다. |
| 비공식 재전송 | 제3자 리레이 호스트, `.php` 주소 | 권리자 허용 여부를 확인할 수 없습니다. |
| DASH | `.mpd` | 검증된 재생 방식이 없습니다. |

CORS로 막힌 스트림도 우회하지 않습니다. 방송사가 CORS를 허용하거나, 사용 권한이 있는 서버 측 프록시를 둬야 합니다.

3. 플레이어의 **전체화면** 버튼을 눌러 봅니다.
4. IPTV 탭에서 상태를 "제외 숨기기"로 두고 **"이 목록 재생 점검"** 을 누르면 테슬라에서의 실제 재생 결과가 각 채널에 기록됩니다.
