# 사신뮤직

뮤직올렛의 장점(광고 없음, 인터넷 없이 기기 안 노래 재생, 여러 개의 대기열)과 사신플레이어식 기능(상단바 가사 표시, 영상 재생, 영상 내려받기)을 합친 새 안드로이드 음악 앱입니다.

## 1. 기능 분석

> "크래프트애니씽"이라는 도구는 이 작업 공간에 없어서 쓰지 못했습니다. 아래 분석은 두 앱의 공개된 기능 설명을 바탕으로 직접 정리했습니다. 두 앱의 프로그램 코드는 보지 않았고 베끼지도 않았습니다. 사신뮤직의 코드는 모두 새로 썼습니다.

### 뮤직올렛에서 가져온 것

| 뮤직올렛 기능 | 사신뮤직 |
|---|---|
| 광고 없음, 인터넷 권한 없이 기기 안 노래만 재생 | 광고 없음. 기기 안 노래는 인터넷 없이 재생 (인터넷 권한은 영상 주소 재생·내려받기에만 씀) |
| 여러 개의 대기열 (최대 20개) | 대기열 20개. 대기열마다 노래 목록, 몇 번째 곡인지, 재생 위치를 따로 기억 |
| 다음에 재생 / 대기열 끝에 추가 / 다른 대기열에 추가 | 노래를 길게 누르면 같은 메뉴 |
| 대기열 안에서 순서 바꾸기·빼기 | 대기열 탭에서 노래를 길게 누름 (위로·아래로·다음 곡으로·빼기) |
| 노래·앨범·가수·폴더 탭 | 같은 탭 + 검색 |
| 싱크 가사 (.lrc), 노래 파일 안의 가사 | .lrc 파일(가사 폴더 지정), MP3 안의 가사, FLAC 안의 가사. 한국 노래 파일에 많은 완성형 한글도 읽음. 가사 줄을 누르면 그 위치로 이동 |
| 수면 타이머, 이퀄라이저, 재생 속도 | 같음 |
| 이어폰 조작, 이어폰을 빼면 멈춤 | 같음 (재생 서비스가 처리) |
| 마지막에 듣던 곳부터 이어 듣기 | 앱을 껐다 켜도 대기열과 위치가 그대로 |
| 알림·잠금화면 조작 | 같음 |

### 사신플레이어식으로 넣은 것

| 기능 | 사신뮤직의 방식 |
|---|---|
| **상단바 가사 표시** | 두 가지를 함께 씁니다. ① **상단바 알림**: 재생 중 지금 가사 줄이 알림 제목으로 바뀜 (권한 필요 없음) ② **상단바 위에 띄우기**: 화면 맨 위 상단바 자리에 가사를 한 줄로 직접 띄움 (다른 앱 위에 표시 권한 필요). 위치(왼쪽·가운데·오른쪽), 배경(투명·검정), 글자 크기를 고를 수 있고, 터치는 아래 화면으로 그대로 통과합니다. 가사가 없으면 "♪ 제목 - 가수"를 보여 줍니다. |
| **영상 재생** | 영상 탭에서 기기 안 영상 재생. 인터넷 영상 주소(파일, 실시간 m3u8)도 재생. 홈 버튼을 누르면 작은 화면(화면 속 화면)으로 계속 재생. 영상의 소리만 음악처럼 백그라운드로 들을 수도 있음 (영상을 길게 누름). 다른 앱에서 영상 파일을 열 때 사신뮤직을 고를 수 있음. |
| **영상 내려받기** | 영상 주소를 넣거나, 다른 앱에서 주소를 "공유 → 사신뮤직"으로 보내면 내려받음. 영상 재생 화면의 "내려받기" 단추도 있음. 안드로이드 내려받기 관리자를 써서 알림에 진행 상황이 보이고, 동영상(또는 음악) › 사신뮤직 폴더에 저장됩니다. |

### 일부러 넣지 않은 것

- **유튜브 등 동영상 사이트에서 영상 뽑아 내려받기**: 사이트 이용 약관과 저작권 문제로 넣지 않았습니다. 파일 주소를 바로 받는 방식이라 내 파일, 나스에 둔 파일, 저작권자가 허락한 파일에 쓰세요.
- **실시간 재생 목록(m3u8) 내려받기**: 파일 하나가 아니라 조각 여러 개라서 지금은 재생만 됩니다.
- **M4A 파일 안의 가사**: 아직 못 읽습니다. 같은 이름의 .lrc 파일을 가사 폴더에 두면 됩니다.

## 2. 쓰는 법

- **처음 켜면** 노래·영상·알림 권한을 묻습니다. 허용해야 노래 목록이 보입니다.
- **노래 누르기** → 지금 보이는 목록 전체가 대기열이 되고 그 노래부터 재생. **길게 누르기** → 다음에 재생, 대기열에 추가 등.
- **아래 작은 재생기 누르기** → 지금 재생 화면 (앨범 그림 / 가사, 오른쪽 위 "그림/가사"로 바꿈).
- **상단바 위에 가사 띄우기**: 설정 탭 → "상단바 위에 가사 띄우기" → 권한 화면에서 사신뮤직 허용 → 돌아오면 켜짐.
- **가사 파일 쓰기**: 설정 탭 → "가사 폴더 고르기" → .lrc 파일이 있는 폴더 선택. 노래 파일 이름과 같은 이름(또는 "가수 - 제목")의 .lrc 파일을 찾습니다.

## 3. 설치 파일 만들기

### 미니피씨에서 만들기

저장소를 미니피씨에 받은 뒤 `music` 폴더에서 아래를 실행합니다. 처음 한 번은 안드로이드 개발 도구(약 300메가바이트)를 받느라 시간이 걸립니다.

**리눅스 미니피씨**

```bash
sudo apt install -y openjdk-17-jdk unzip git      # 처음 한 번만
git clone https://github.com/junghwan1570/tvwa.git
cd tvwa/music
./미니피씨_빌드.sh                                  # → music/사신뮤직.apk
./미니피씨_빌드.sh /mnt/나스/앱                       # → 만든 뒤 나스 폴더에도 복사
```

나스 공유 폴더를 리눅스에 연결(마운트)하는 예 (시놀로지 공유 폴더 "앱"):

```bash
sudo apt install -y cifs-utils
sudo mkdir -p /mnt/나스/앱
sudo mount -t cifs //나스주소/앱 /mnt/나스/앱 -o username=나스아이디,uid=$(id -u),gid=$(id -g)
```

**윈도우 미니피씨** (파워셸)

```powershell
winget install EclipseAdoptium.Temurin.17.JDK      # 처음 한 번만
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned # 처음 한 번만
cd C:\sasin\tvwa\music                              # 경로에 한글이 없는 곳 권장
.\미니피씨_빌드.ps1                                  # → music\사신뮤직.apk
.\미니피씨_빌드.ps1 \\나스이름\앱                     # → 만든 뒤 나스 폴더에도 복사
```

- 만든 설치 파일을 나스에 두면 휴대폰에서 나스 앱(시놀로지 파일 앱 등)으로 받아 바로 설치할 수 있습니다.
- 서명 키(`ci-temp.keystore`)는 처음 만들 때 한 번 생기고 계속 같은 키를 씁니다. 이 파일을 지우면 다음 설치 파일은 기존 앱을 지우고 새로 설치해야 합니다. 나스에 백업해 두세요.
- 깃허브 자동 빌드로 만든 설치 파일과 미니피씨에서 만든 설치 파일은 서명 키가 달라서 서로 덮어 설치가 안 됩니다. 한쪽만 쓰거나, 같은 키(`release.keystore` + 비밀번호 환경변수 `KEYSTORE_PASSWORD`)를 양쪽에 두세요.

### 깃허브에서 자동으로 만들기

`main`에 `music` 폴더 변경이 올라가면 깃허브가 자동으로 시험을 돌리고 설치 파일을 만들어 **"사신뮤직 (최신)"** 릴리스(`music-latest`)에 올립니다. 깃허브는 릴리스 파일 이름의 한글을 깨뜨리기 때문에 그 파일 이름만 `SasinMusic.apk`입니다.

## 5. 코드 구성

| 파일 | 하는 일 |
|---|---|
| `MainActivity.kt` | 노래·앨범·가수·폴더·영상·대기열·설정 탭, 검색, 아래 작은 재생기 |
| `NowPlayingActivity.kt` | 지금 재생 화면: 앨범 그림, 싱크 가사, 조작 단추 |
| `VideoActivity.kt` | 영상 재생, 작은 화면, 내려받기 |
| `PlaybackService.kt` | 백그라운드 재생, 알림·잠금화면, 상단바 가사, 수면 타이머, 이퀄라이저, 대기열 저장 |
| `StatusOverlay.kt` | 상단바 위에 가사 띄우기 |
| `Lyrics.kt` | .lrc 파일·노래 파일 안의 가사 읽기 |
| `Queues.kt` | 대기열 20개 저장·불러오기 |
| `Library.kt` | 기기 안 노래·영상 목록 |
| `Downloader.kt` | 영상·음악 내려받기 |
